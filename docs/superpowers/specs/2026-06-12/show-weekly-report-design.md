# show-weekly-report — 설계

**날짜**: 2026-06-12

## 목적

이번 주(또는 지정한 기간) 동안 **내가** 무슨 작업을 했는지를, 현재 git 저장소의
커밋 내역만 조사해 **개발을 모르는 대표님도 빠르게 훑어볼 수 있게** 주제별로
묶은 한국어 요약으로 대화창에 보여준다.

**대상 독자는 비개발자 의사결정자다.** 전문 용어·내부 스킬명·파일 경로·구현
세부는 빼고, "이번 주에 무엇을 했는가"만 직관적으로 보이게 한다.

예시 출력:

```
## 이번 주 작업 (06.08~06.12)

- **이미지 부분 수정 기능 구현** (06.09~06.10)
  - 원하는 영역만 골라 고치는 도구 추가 (06.09)
  - 색칠하듯 영역을 지정하는 방식 추가 (06.10)
    - 확정 후 자동 저장·정리까지 마무리 (06.10)
- **사용자(고객) 관점 점검 도구 구현** (06.09)
  - 가상 고객으로 사용성·아이디어를 점검 (06.09)
- **아이디어 사전 검증 도구 구현** (06.08)
- **디자인 자동화 기능 보강** (06.08~06.09)
  - 디자인을 실제 화면 코드로 바꾸는 기능 추가 (06.08~06.09)
  - 로고·아이콘 생성 방식 개선 (06.08)
```

## 성격

스크립트 없는 **산문(prose) 스킬**. `git log`를 Bash로 실행해 커밋을 모으고,
Claude가 주제별로 묶어 요약하는 절차를 SKILL.md 산문으로 규정한다.
(discussion 스킬과 동일한 결 — 전용 파서/스크립트 없음.)

## 위치

`skills/show-weekly-report/SKILL.md`

## 트리거

"이번주 작업 요약해줘", "show-weekly-report", "이번 주 뭐 했는지 정리" 등.

## 입력 (인자)

- **인자 없음** → 이번 주 월요일 00:00 ~ 지금 (기본값)
- **인자 있음** → git에 그대로 넘기는 기간 표현.
  - 예: `2026-06-01..`, `--since="3 days ago"`, `2026-06-01..2026-06-07`

## 처리 흐름

1. **저장소 확인** — git 저장소가 아니면 안내 후 종료.
2. **기간 결정** — 인자 없으면 이번 주 월요일을 기본으로 계산
   (`git log --since=...`에 해당하는 표현). 인자 있으면 그것을 사용.
3. **작성자 한정** — `git config user.email` 결과로 본인 커밋만
   (`--author=<email>`). 본 저장소 기준 `ansgur119977@gmail.com`.
4. **수집** — `git log <range> --author=<me> --stat`로 커밋 메시지
   (subject + body)와 파일 변경 통계(어떤 파일이 얼마나 바뀜)를 함께 수집.
   diff **본문은 읽지 않는다**(가벼움 유지).
5. **분류·요약** — 커밋을 주제별로 묶고, 변경된 파일 경로로 "어느 부분"인지
   판단한다. **비개발자 눈높이**로 옮긴다:
   - 전문 용어·내부 스킬명·파일 경로·`§`/`R번호` 같은 내부 기호를 쓰지 않는다.
     ("`image-edit-region` 스킬" → "이미지 부분 수정 기능")
   - 큰 주제를 상위 항목으로, 그 안의 갈래를 하위 항목으로 **최대 3단계까지**
     중첩한다(필요 없으면 1~2단계).
   - **모든 깊이의 항목에 날짜를 붙인다.** 단일 날짜면 `(MM.DD)`, 여러 날짜에
     걸치면 `(MM.DD~MM.DD)`. 상위 항목 날짜는 그 하위들을 아우르는 범위로 잡는다.
6. **출력** — 대화창에 마크다운으로 직접 출력. 맨 위에 `## 이번 주 작업
   (시작~끝)` 헤더 한 줄. **파일 저장 없음.**

## 엣지 케이스

- 해당 기간 커밋 0건 → "이번 기간 커밋이 없습니다" 안내.
- git 저장소 아님 → 안내 후 종료.
- 커밋이 너무 많으면(예: 50+) 주제 묶음 위주로 압축하고 사소한 커밋은 합쳐서
  표현한다. 묶을 때 정보 손실이 있으면 그 사실을 한 줄로 알린다.

## 비범위 (YAGNI)

- 여러 저장소 동시 집계
- diff 본문 읽기
- 전체 작성자(--all) 옵션

나중에 필요해지면 인자로 확장한다.
