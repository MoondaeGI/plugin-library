# 브랜드 킷 이미지 아트 디렉션 가이드

`design-brand-kit`이 **이미지를 생성할 때 참조**하는 아트 디렉션 가이드다. 목표는 "괜찮은 AI 이미지"가 아니라 **진지한 아이덴티티 스튜디오가 만든 것 같은 프리미엄 브랜드 결과물**이다.

이 가이드는 도구 중립이다 — Codex 내장 `image_gen`이 생성하든 사람이 외부 도구로 만들어 드롭하든, 결과물이 도달해야 할 품질·구성 기준을 정의한다.

## 산출물 (두 가지)

1. **단색 클린 로고 (필수)** — 독립된 깨끗한 로고 이미지. 단색(흑/백) 버전 고려, 배경 깔끔. → `.design/generated/logo/`. (향후 `design-logo` 수정 스킬의 입력이 되므로 보드에 박힌 형태가 아니라 **단독**으로도 만든다.)
2. **브랜드 킷 오버뷰 보드** — 로고·구성·적용·색·타이포·태그라인·이미지를 한 장에 담은 **프리미엄 다패널 보드**. → `.design/generated/brand-kit/`.

두 산출물 모두 한 개씩 만들고 → 보여주고 → 한 번에 한 가지만 고쳐 재생성하는 협업 루프로 진행한다(SKILL.md "흐름" 참고).

## 품질 기준

결과물은 다음처럼 느껴져야 한다: 의도적(intentional), 프리미엄, 미니멀, 일관성 있음, 전략적, 시각적으로 비싸 보임, 브랜드 시스템 기반, 프레젠테이션 준비됨.

만들지 말 것: 평범한 로고, 랜덤 목업, 지저분한 AI 무드보드. **한 장 안에 완결된 브랜드 세계**를 만든다.

## 1. 전략 먼저 (의미 기반 디자인)

생성 전에 브랜드 전략을 추론한다: 카테고리 / 타깃 / 제품 기능 / 감정적 약속 / 문화적 위치 / 신뢰 수준 / 시각 세계 / **상징 메타포** / 피해야 할 것. 시각 시스템은 미관이 아니라 **의미**에서 나온다.

카테고리 → 심볼 논리 예시:

| 카테고리 | 핵심 아이디어 | 가능한 심볼 논리 |
|---|---|---|
| 개발자 도구 | 구축·속도·정밀·제어 | 커서, 프레임, 볼트, 스캐폴드, 그리드 |
| AI 어시스턴트 | 위임·지능·명료 | 스파크, 궤도, 시그널, 패스, 노드 |
| 보안 | 보호·경계·감시 | 실드, 눈, 씰, 보호된 코어 |
| 게이밍/베팅 | 운·보상·긴장·속도 | 주사위, 젬, 카드, 시그널, 트로피 |
| 보이스 AI | 소리·리듬·명령·흐름 | 웨이브폼, 마이크, 오브, 스피치 패스 |
| 컴플라이언스 | 신뢰·질서·규칙 | 씰, 배지, 문서, 실드 |
| 드론/로보틱스 | 비행·제어·시야·미션 | 윙, 아울, 크로스헤어, 패스, 존 |
| 럭셔리/에디토리얼 | 취향·소재·의례·절제 | 모노그램, 씰, 종이, 엠보스, 마크 |
| 생산성 | 집중·모멘텀·명료 | 패스, 체크, 블록, 라이트 |

심볼을 랜덤하게 고르지 않는다.

## 2. 로고 생성 표준

로고는 **단순·기억성·상징적·확장 가능·소유 가능(ownable)·시각적 균형**, 그리고 브랜드 아이디어와 연결되어야 한다. 아이콘·워드마크·배지·UI 마크·패턴으로 쓸 수 있어야 한다.

피할 것: 정당화 없는 번개, 랜덤 동물, 가짜 럭셔리 크레스트, 유명 마크 모방, 과도하게 복잡한 심볼, 클립아트 아이콘, 의미 없는 반짝임(sparkle), 일관성 없는 변형. 로고는 **리서치와 축약**에서 나온 느낌이어야 한다.

### 로고 컨셉 방법 (하나, 최대 둘 조합)

1. **모노그램 + 의미** — 브랜드 이니셜 + 메타포 (예: `K`+kite/frame, `S`+sound wave). 지루한 글자 아이콘 금지 — 네거티브 스페이스·컷·폴드·기하 사용.
2. **제품 액션** — 제품의 핵심 동작을 심볼로 (build→frame/scaffold/cursor, protect→shield/boundary, speak→waveform/pulse, automate→loop/path). 직설적이지 않고 추상·프리미엄하게.
3. **메타포 융합** — 의미 있는 두 아이디어를 하나의 축약 마크로 (owl+drone vision, shield+mountain, cursor+speed). 미묘하고 읽히게.
4. **네거티브 스페이스** — 빈 공간으로 지능을 만든다 (숨은 화살표, 보호된 중심, 컷아웃 이니셜, 내부 패스). 선명하게.
5. **구성 기하(construction geometry)** — 명확한 시스템에서 마크를 만든다 (원, 대각 컷, 그리드, 프레임, 모듈 블록, 궤도, 크로스헤어, 측정된 선). 보드의 한 패널이 이 구성 논리를 보여줄 수 있다.

## 3. 브랜드 킷 오버뷰 보드 구성

강한 보드는 **큐레이션된 시퀀스**처럼 느껴진다. 모든 패널이 똑같이 시끄럽지 않게 — 리듬을 둔다: 조용함 / 기능적 / 감정적 / 기술적 / 분위기 / 디테일.

### 기본 레이아웃: 3 × 3 (지정 없으면)

- 종횡비 `4:3` 또는 `16:10`, 강한 거터(gutter), 일관된 정렬, 절제된 네거티브 스페이스.
- 다크 차콜 또는 라이트 캔버스(비주얼 모드에 따라).

기본 9패널:

1. **로고 커버** — 큰 로고/워드마크, 미니멀 타이틀, 강한 네거티브 스페이스.
2. **로고 구성** — 심볼 분해/그리드/기하/네거티브 스페이스 논리. 왜 이 마크인지 보여줌.
3. **디지털 적용** — 브라우저 크롬, 앱 헤더, 터미널, 대시보드 조각, 앱 아이콘.
4. **브랜드 에센스** — 짧은 태그라인 하나, 큰 가독 타이포, 희소한 구성.
5. **컬러 시스템** — 스와치, 그라데이션 스트립, 컬러 디스크, 머티리얼 칩, 팔레트 카드.
6. **타이포그래피** — 큰 타입 스페시먼, 알파벳 행, 또는 주/보조 타입 페어링.
7. **물리적 적용** — 카드, 폴더, 배지, 포스터, 라벨, 씰, 패키징, 오브젝트 목업.
8. **이미지 디렉션** — 시네마틱 풍경, 제품 크롭, 하프톤 포스터, 에디토리얼 씬, 머티리얼 텍스처. (무드보드/분위기는 여기에 담긴다.)
9. **시스템 디테일** — UI 칩, 인풋 바, 커맨드 라인, 아이콘 행, 배지 시스템, 컴포넌트 스트립, 패턴 디테일.

### 허용 레이아웃

`3×3` 풀 아이덴티티 / `2×3` 시네마틱 덱 개요 / `2×2` 컴팩트 컨셉 보드 / `1×3` 가로 브랜드 스트립 / `4×2` 와이드 콘택트 시트 / 요청 시 커스텀.

## 4. 비주얼 모드 (브랜드에 맞게 선택)

- **다크 디벨로퍼/빌더** (개발툴·코딩 에이전트·인프라): near-black 패널, 모노스페이스, 커맨드 라인/터미널/프롬프트 바, 미묘한 그리드, cyan/blue/coral/lime 액센트. 로고: cursor+frame, bolt, scaffold+모노그램. 무드: 정밀·날카로움·빌더 네이티브.
- **다크 프로덕트/오퍼레이터** (비즈/그로스/세일즈/생산성): black/dark red/amber, 글로우 UI 칩, 카드 시스템, 세그먼트 플로우, 아이콘 행, 리워드/진행 모티프. 로고: signal/gift/path/switch/loop. 무드: 빠름·전술적·프리미엄.
- **다크 네이처/캄 시스템** (전략·트래블·웰니스·조용한 프리미엄 SaaS): deep green + lime, 안개 풍경, 이미지 UI 원, 소프트 오버레이, 다크 에디토리얼 그리드. 로고: path/leaf/moon/horizon/compass. 무드: 차분·신뢰·집중.
- **다크 시큐리티/위협 인텔** (보안·컴플라이언스·모니터링): black/navy, 실드 폼, 레이더 라인, 위협 라벨, 모션 트레이스, red/blue 알림 칩. 로고: shield/raptor/eye/watch/boundary. 무드: 진지·경계·정밀.
- **라이트 에디토리얼/컴플라이언스** (법률·프라이버시·문서·신뢰): warm ivory, 종이 텍스처, 작은 세리프 라벨, 씰/배지, 컬러 휠, deep blue/red/gold 액센트. 로고: seal/badge/document/stamp/monogram. 무드: 신뢰·세련·기관적이되 모던.
- **럭셔리/뷰티/패션**: ivory/stone/espresso, 세리프 워드마크, 엘레강트 모노그램, 종이 그레인, 엠보싱, 제품 라벨, 에디토리얼 크롭, 소프트 섀도. 로고: monogram/seal/refined typographic mark. 무드: 고급·성숙·비싸 보임.
- **보이스/커뮤니케이션**: dark indigo, lilac glow, 웨이브폼, 마이크 모티프, 폰 크롭, 커맨드 인풋. 로고: wave+이니셜/sound orb/speech path/pulse ring. 무드: 유려·지적·친밀.
- **컬처럴/실험적** (음악·창작툴·이벤트·게이밍 인접): 하프톤, CRT 텍스처, 아날로그 프린트, 볼드 액센트, 포스터형 패널, 예상 밖 크롭. 로고: 커스텀 워드마크/태도 있는 아이콘/프린트 마크. 무드: 기억성·창의적이되 통제됨.

## 5. 색 규율

하나의 지배적 팔레트: base + primary accent + secondary accent + neutrals. 액센트는 패널 전반에 **반복**된다. 랜덤 무지개·싸구려 네온 금지, 정당화 없는 보라-파랑 AI glow 금지. 액센트 하나가 전체 시스템을 끌고 갈 수 있다.

참고 팔레트: black+cyan+muted coral / black+red+cream+blue / forest green+lime+fog gray / navy+white+steel / ivory+deep blue+red+gold / black+lilac+soft purple / black+amber+red / charcoal+white+pale blue.

## 6. 텍스트 규칙 / 태그라인

이미지 모델은 텍스트를 부정확하게 렌더하므로 **텍스트는 아주 적게, 크고 희소하게** 둔다.

- 좋음: 브랜드명, 태그라인 하나, URL 하나, 커맨드 하나, 섹션 라벨 2~5개, 짧은 UI 칩.
- 나쁨: 긴 문단, 가짜 본문, 메뉴 항목 다수, lorem ipsum, 빽빽한 설명, 안 읽히는 라벨.

태그라인은 짧고 구체적으로 (예: "Nothing random.", "On guard.", "Build better.", "Clarity builds confidence."). 일반 기업 슬로건·버즈워드·가짜 영감 문구 금지.

> 정확한 색 HEX·폰트 이름 같은 **권위 있는 스펙은 이미지가 아니라 `BRAND_KIT.md`/`brand-tokens.json`에** 둔다. 보드의 텍스트는 프레젠테이션용 최소 표기일 뿐이다.

## 7. 이미지·목업 디렉션

- **이미지**: 아트 디렉션된 느낌 — 시네마틱 산/석양, 브랜드 오버레이 풍경, 하프톤 구름, CRT 화면, 다크 제품 클로즈업, 텍스처 종이, 무디 건축. 금지: 일반 스톡 인물, 랜덤 오피스 사진, 클리셰 로봇, 과밀 씬. 팔레트·메타포와 일치.
- **목업**: 미니멀하고 믿을 만하게 — 브라우저 크롬, URL 바, 터미널, 커맨드 프롬프트, 앱 아이콘, 폰 코너 크롭, 카드 스택, 배지, 씰, 폴더, UI 칩, 대시보드 조각, 인풋 바, 제품 라벨. 금지: 데이터 과밀 가짜 대시보드, 싸구려 글로시 목업, 디바이스 과잉, 빽빽한 앱 화면. **목업은 기능 데모가 아니라 아이덴티티 적용이다.**

## 8. 프리미엄 디테일 언어

작은 페이지 번호, 작은 푸터 라벨, 정렬 마크, 구성 라인, 미묘한 크로스헤어 그리드, 얇은 룰, 브라우저 바, 라운드 사각형, 이미지 마스크, 소프트 섀도, 저투명 텍스처, 하프톤 처리, 강조 단어 하나, 액센트 칩 하나. **남용 금지** — 디테일은 가까이 봤을 때 보상이 되어야 한다.

## 9. anti-generic (절대 만들지 말 것)

랜덤 떠다니는 아이콘, 일반 스타트업 그라데이션, 과설계 로고, 의미 없는 blob, 지저분한 콜라주, 가짜 작은 UI, 일관성 없는 로고 변형, 색 과다, 싸구려 네온, 스톡 템플릿 보드, 기업 파워포인트 슬라이드, 영혼 없는 SaaS 대시보드. → 더 조용하고, 더 날카롭고, 더 의도적으로.

## 10. 우리 파이프라인 연결

- **입력**: `BRAND_KIT.md`(전략·시각 방향·로고 방향·금지 패턴)와 `brand-tokens.json`(색·타이포 토큰)에서 전략·팔레트·타이포를 읽어 보드/로고에 반영한다.
- **권위**: 색 HEX·폰트 스펙의 정답은 md/tokens. 이미지는 시각 레퍼런스 + 프레젠테이션.
- **저장**: 단색 클린 로고 → `.design/generated/logo/`, 오버뷰 보드 → `.design/generated/brand-kit/`. 파일명 식별 가능(`logo-concept-1.png`, `brand-board-1.png`), 재생성 시 버전(`-v2`)으로 기존 확정본을 덮지 않는다.
- **협업 루프**: 한 장씩 생성 → 보여주고 피드백 → 한 번에 한 가지만 고쳐 재생성 → 확정 → 다음.

## 11. 프롬프트 템플릿 (내부 구조)

`image_gen` 호출 시 다음 구조로 프롬프트를 구성한다(브리프의 "이미지 생성 Prompt"에 반영):

```text
Create a premium brand-kit overview image for "[BRAND NAME]".

Brand strategy:
- category: [category]
- audience: [audience]
- personality: [traits]
- core metaphor: [metaphor]
- logo idea: [symbol + name + category meaning를 어떻게 결합하는지]

Layout: [3×3 / 2×3 / custom] grid on a [dark/light] presentation canvas, strong gutters, clean alignment, refined negative space.

Panels: logo cover · logo construction · digital application · tagline/essence · color system · typography · physical application · image direction · system detail

Visual mode: [모드]
Palette: [절제된 팔레트 — brand-tokens.json 기반]
Style: premium, sparse, cinematic, intentional, polished, brand-guidelines deck, no clutter, no copied real-world logos.
Typography: readable, minimal, high hierarchy, no tiny fake text.
Logo: professional, symbolic, simple, ownable, brand-purpose based, repeated consistently across panels.
```

단색 클린 로고는 별도 호출로: 같은 전략·메타포·팔레트를 쓰되 `Use case: logo-brand`, 단일 마크/워드마크를 깨끗한 단색 배경에 크게, 단색(흑/백) 버전 고려, 텍스트 최소.
